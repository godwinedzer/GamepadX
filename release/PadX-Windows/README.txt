PadX Windows Server

1. Install ViGEmBus on the Windows PC before running the server.
2. Keep the Android phone and Windows PC on the same local network.
3. Run `start_server.bat`.
4. If Windows Firewall asks for permission, allow it.
5. The server will show the PC IP address.
6. Open the PadX Android app and enter that IP address.
7. Connect and test the controls.

Files in this folder:
- server.exe      = Windows server program
- server.pdb      = debug symbols
- start_server.bat = easy launcher

If the controller does not work:
- confirm ViGEmBus is installed
- confirm port 8888 is not blocked
- confirm phone and PC are on the same Wi-Fi
